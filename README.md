# cryoanalgesia-la-evidence-map
Reproduction assets for a scoping review mapping primary comparative evidence of cryoanalgesic vs local-anesthetic techniques. Unit of analysis: unique patient cohort.

- `CANONICAL_COUNTS.*` — single source of all reported numbers.
- `PRIMARY_STUDY_MAP.csv` — 414 primary study reports (Tier A/B/C).
- `TIER_A_COMPLETE.csv`, `SYNTHESIS_REPORTS.csv`, `PROTOCOLS_ONGOING.csv`, `MASTER_RECORDS.csv` — full datasets.
- `SEARCH_STRATEGIES_FULL.md`, `SEARCH_YIELDS.csv`, `SEARCH_EXPORT_MANIFEST.csv`, `SENTINEL_RETRIEVAL_TEST.csv`, `DATA_ACQUISITION_LEDGER.csv` — search documentation.
- `PRISMA_FLOW_DATA.csv`, `PRISMA_FLOW_FINAL.png`, `Figure2_domain_tier.png`, `Figure3_year_tier.png` — figures and flow data.
- `scripts/` — search, dedup, screening, classification, dataset-finalization and figure/document builders (chronological pipeline).
