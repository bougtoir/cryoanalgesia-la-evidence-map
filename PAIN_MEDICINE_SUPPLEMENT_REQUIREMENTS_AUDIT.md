# Pain Medicine / OUP supplement requirements audit

Source: official Instructions to Authors, https://academic.oup.com/painmedicine/pages/general_instructions (revised October 2026), plus published-article evidence on academic.oup.com.

Verified:
- Article type: "Systematic or Scoping Review Article" — 5,000 words (excl. title page, abstract, references, tables, figures), no reference limit, structured abstract ≤350 words, PRISMA-ScR required ("You must follow the PRISMA-ScR guidelines and checklist"), OSF registration required, review type stated in title.
- PRISMA-ScR checklist: required to follow; submitted as a checklist file (analogous to CONSORT checklist, which is uploaded as a supplementary data file at initial submission). We upload PRISMA_ScR_CHECKLIST_FINAL.docx.
- Complete electronic search strategies: not named as a mandatory separate file, but transparency standard for ScR → provided once as Supplementary Appendix S1 (single file, not eight).
- ZIP supplementary files: ACCEPTED in practice — published Pain Medicine articles host "pnadXXX_Supplementary_Data - zip file" as online supplementary data (e.g., 10.1093/pm/pnad085). We therefore use ONE compact Supplementary_Data.zip for datasets.
- CSVs individually: permitted technically but undesirable; consolidated into the single zip instead.
- External public repository: Data availability statements on OUP articles routinely cite external repositories; used for the full reproducibility archive (immutable tag v1.0-submission).
- Supplementary material is published online with the paper ("Supplementary material is available at Pain Medicine online").
- File-size limits: none found in the instructions; package kept small regardless.

Decision: ONE Supplementary Appendix S1 (search strategies) + ONE Supplementary_Data.zip (datasets) + PRISMA-ScR checklist. No internal QC file is uploaded.
